---

# Install Plugin

If distributed through npm:

```bash
npm install -g superpowers-optimized
```

---

# Register Plugin in Codex

```bash
codex plugin add superpowers-optimized
```

---

# Alternative Manual Configuration

Add inside:

```txt
~/.codex/config.toml
```

Example configuration:

```toml
[plugins.superpowers_optimized]
enabled = true
mode = "performance"
token_optimization = true
```

---

# Recommended Optimization Settings

Example advanced configuration:

```toml
[plugins.superpowers_optimized.settings]
context_compression = true
smart_memory = true
prompt_trimming = true
cache_responses = true
```
