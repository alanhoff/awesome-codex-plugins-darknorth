# grill-me Skill

> A Codex skill designed to improve understanding through iterative clarification and guided questioning.

The **grill-me Skill** helps Codex ask targeted follow-up questions before generating solutions, ensuring better context alignment and more accurate outputs.

# Setup

## Installation

Add the skill configuration to your Codex workflow or agent setup.

```json
{
  "skill": "grill-me",
  "mode": "interactive-clarification"
}
```

---

## Recommended Workflow

1. User submits an initial request
2. grill-me Skill asks clarifying questions
3. Missing requirements are identified
4. Codex generates a refined solution
5. Iteration continues until requirements are complete

---

# Example Workflow

## User Prompt

```txt
Build me a dashboard app
```

## grill-me Skill Response

```txt
What type of dashboard do you want?
Who are the users?
What framework should be used?
Do you need authentication?
Should the dashboard support mobile devices?
What data sources will it connect to?
```

## Final Outcome

A significantly more accurate and context-aware implementation.
