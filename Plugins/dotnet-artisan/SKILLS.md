# dotnet-artisan

> A comprehensive .NET development plugin for OpenAI Codex that provides specialized workflows, agents, and tooling for modern .NET application development.

dotnet-artisan helps developers and AI coding agents build, manage, debug, and scale .NET applications using structured workflows for C#, ASP.NET Core, EF Core, Blazor, MAUI, cloud-native systems, and DevOps pipelines.

Make sure you have:
- OpenAI Codex CLI installed

---

# Install .NET SDK

Download and install:

```txt
https://dotnet.microsoft.com/download
```

Verify installation:

```bash
dotnet --version
```

---

# Register Plugin in Codex

```bash
codex plugin add dotnet-artisan
```

---

# Alternative Manual Configuration

Add inside:

```txt
~/.codex/config.toml
```

Example configuration:

```toml
[plugins.dotnet_artisan]
enabled = true
framework = ".NET 8"
mode = "enterprise-development"
```
